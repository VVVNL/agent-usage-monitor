Everything you need to pace yourself

Built for people who live in a terminal with an AI coding agent and would rather not discover a limit by hitting it.

Real limits, not estimates

Percentages and reset times are exactly what the provider reports. If a value is unavailable, the widget says so instead of guessing.

Tray icon and floating widget

A glanceable tray icon with the number on it, plus an optional always-on-top widget with opacity, themes, compact mode and click-through.

Who is working right now

See sessions that are working, waiting for your input, or just finished, with counts only. Optionally includes sessions running inside WSL.

Alerts that respect you

Optional notifications at 75% and 90%, when a limit is used up, or when it resets. One alert per event, never a stream.

Light on your machine

One small native program, around 13 MB, with no background service. It checks every few minutes (your choice) and sleeps the rest of the time.

Multi-monitor aware

The widget remembers where you put it, and returns there when a display comes back after you unplug it.

How it works

It does not scrape a website or read tokens. It asks the tool you already use.

  1. Runs your CLI

    Every few minutes it runs claude’s own usage command, with no shell involved and without saving a transcript.

  2. Reads the answer strictly

    The text is parsed by a fail-closed parser. Anything unexpected becomes a clear “can’t read usage” message, never a wrong number.

  3. Shows it where you look

    The tray, the widget and optional notifications all show the same figures, with how stale they are.

Private by design

The whole point is that it stays on your computer.

  • Never opens your Claude or Codex credential files, keychain entries or tokens.
  • Never reads conversations, transcripts or project files.
  • Never modifies Claude Code files or settings.
  • No telemetry, analytics or crash reporting. No account, no backend.
  • Checking usage costs no quota: the usage command makes no model call.
  • Update notifications are optional and off until you say yes; they only tell you, they never download or install anything.

Questions

Does it work with a Claude Team or Enterprise plan?

It shows whatever Claude Code’s own usage command shows for the account you are signed in with, so it follows your plan.

Will it use up my quota?

No. The usage command makes no model call. It costs zero tokens.

Why does Windows warn me about the installer?

The builds are unsigned for now, and SmartScreen is cautious with unsigned, little-downloaded files. Verify the SHA-256 checksum from the release page if you want to be sure the file is intact. Signing is planned.

Where does it store things?

Only a few small files in your user settings folder (settings, a cache of the last numbers, and notification memory). The tray menu has “Open settings folder”. Deleting that folder resets everything.

Is it official?

No. It is an independent open-source project, not affiliated with or endorsed by Anthropic or OpenAI.
