Know how much Claude Code you have left.

A small widget that sits on your screen and shows your Claude Code usage limits, when they reset, and whether Claude is still working.

Prefer it tiny? Switch to compact mode.

  1. 1

    Session limit

    How much of your current session allowance you’ve used, and when it starts over.

  2. 2

    Weekly limit

    The same for the whole week. The bar turns green, amber from 75%, and red from 90%.

  3. 3

    Is Claude working?

    How many Claude Code sessions are busy right now. It also tells you when one is waiting for your answer, or has just finished.

  4. 4

    How fresh the numbers are

    It checks every few minutes (you choose how often). If the numbers get old, it says so.

Get started in three steps

  1. 1

    Have Claude Code ready

    Claude Code must be installed and signed in. If claude works in a terminal, you’re set.

  2. 2

    Download and run the installer

    Get agent-usage-monitor-…-setup.exe from the releases page. No admin rights needed. Windows may say “unknown publisher” because the app isn’t signed yet: choose More info, then Run anyway.

  3. 3

    Look at your screen

    The widget appears in the top-right corner and an icon appears in the system tray. Drag the widget anywhere; right-click the tray icon for settings.

Go to the releases page

Also there: a macOS version (beta, not yet tested on a real Mac) and a command-line tool for Linux.

Stays on your computer

It asks Claude Code for the same numbers you’d see by typing /usage. It never reads your passwords or conversations, sends none of your data anywhere, and checking doesn’t use up your allowance. The only thing it can ask the internet, if you allow it, is whether a newer version exists.
